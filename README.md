# Better Renaming for Herdr

Keep Herdr pane labels synchronized with the session titles generated by Claude
Code, Codex, Kimi Code, and OpenCode. The plugin reads only local agent state and
uses Herdr's built-in CLI; it makes no network requests and installs no npm
packages.

## Install locally

Requires Herdr 0.7+ and Node.js 22.5+.

```sh
herdr plugin link /home/will/projects/herdr-better-renaming
herdr plugin action invoke install-integrations --plugin vimeflow.better-renaming
```

Restart any already-running agents once so Herdr can capture their session IDs,
then sync existing panes:

```sh
herdr plugin action invoke sync-all --plugin vimeflow.better-renaming
```

New titles update automatically on agent detection, state changes, focus, and
Herdr startup. A manually assigned pane label always wins; clear that label to
resume automatic titles.

## Share from GitHub

Publish this directory as a public repository and add the `herdr-plugin` topic.
Others can then install it with:

```sh
herdr plugin install OWNER/herdr-better-renaming
herdr plugin action invoke install-integrations --plugin vimeflow.better-renaming
```

The Herdr marketplace indexes public repositories carrying the
`herdr-plugin` topic automatically.

## Title sources

- Claude Code: `ai-title` / `custom-title` transcript rows, then terminal title
- Codex: `~/.codex/session_index.jsonl` `thread_name`
- Kimi Code: session `state.json` title, then the first user prompt on versions
  that no longer persist a generated title
- OpenCode: the session title in `opencode.db`, then terminal title

Default agent data roots honor `CLAUDE_CONFIG_DIR`, `CODEX_HOME`,
`KIMI_CODE_HOME`, `OPENCODE_DB_PATH`, and the XDG data/state variables.
