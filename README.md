# Agent Title Sync for Herdr

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

Keep Herdr pane labels synchronized with the session titles generated by Claude
Code, Codex, Kimi Code, and OpenCode. The plugin reads only local agent state and
uses Herdr's built-in CLI; it makes no network requests and has no runtime npm
dependencies.

Pairs with [herdr-agent-watcher](https://github.com/winoooops/herdr-agent-watcher),
which adds coding-agent observability to Herdr: live sidebar cards, lifecycle
notifications, and per-pane agent metadata.

## Install from GitHub

Requires Herdr 0.7.5+ and Node.js 22.18+.

```sh
herdr plugin install winoooops/herdr-agent-title-sync
herdr plugin action invoke install-integrations --plugin herdr-agent-title-sync
herdr plugin action invoke start-watcher --plugin herdr-agent-title-sync
```

Restart any already-running agents once so Herdr can capture their session IDs.
The watcher checks local pane and session state once per second, starts with
Herdr, and exits if the plugin is disabled or Herdr becomes unavailable. It
replaces an older watcher when started again, so only one instance remains.
A manually assigned pane label always wins; clear that label to resume automatic
titles.

## Local development

```sh
git clone https://github.com/winoooops/herdr-agent-title-sync.git
cd herdr-agent-title-sync
npm ci
herdr plugin link "$PWD"
herdr plugin action invoke install-integrations --plugin herdr-agent-title-sync
herdr plugin action invoke start-watcher --plugin herdr-agent-title-sync
```

## Configuration

`HERDR_AGENT_TITLE_SYNC_INTERVAL_MS` sets the polling interval in milliseconds.
It must be a positive number and defaults to `1000`. Restart the watcher after
changing it:

```sh
HERDR_AGENT_TITLE_SYNC_INTERVAL_MS=2000 \
  herdr plugin action invoke start-watcher --plugin herdr-agent-title-sync
```

For the same value to apply when Herdr starts the watcher automatically, set the
variable in the environment used to launch Herdr.

## Title sources

- Claude Code: `ai-title` / `custom-title` transcript rows, then terminal title
- Codex: `~/.codex/session_index.jsonl` `thread_name`, with an exact
  `codex resume <session-id>` process fallback when Herdr has not reported the
  session yet
- Kimi Code: session `state.json` title, then the first user prompt on versions
  that no longer persist a generated title
- OpenCode: the session title in `opencode.db`, then terminal title

Agents without a dedicated title reader use their terminal title automatically.
Adding another reader requires one file under `src/adapter/` and one entry in
`src/adapter/index.ts`'s `TITLE_READERS` map. Shared parsing and safety helpers
live in `src/adapter/utils.ts`.

Default agent data roots honor `CLAUDE_CONFIG_DIR`, `CODEX_HOME`,
`KIMI_CODE_HOME`, `OPENCODE_DB_PATH`, and the XDG data/state variables.
